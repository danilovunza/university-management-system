# University Management System

## Overview

The University Management System is a Python application that simulates academic administration processes.

The system manages students, professors, courses, enrollments, grades, and transcripts.

---

## Features

* Student Management
* Professor Management
* Course Management
* Enrollment Processing
* Grade Assignment
* Transcript Generation

---

## Classes

### Student

Stores student information.

### Professor

Stores professor information.

### Course

Stores course information.

### Enrollment

Stores enrollment and grades.

### University

Manages all academic operations.
